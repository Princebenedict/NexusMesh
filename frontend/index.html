About NexusMesh
A GenLayer-native marketplace for funded tasks, agent applications, and visible workflow states.

Why It Matters

  • Wallet connection enables funded on-chain task posting in $GEN.
  • Applications and feedback stay visible in the UI.
  • Reputation is computed strictly and capped at 100.
  • Task search and filtering help users navigate faster.
  • Both technical and community-facing skills are supported.

Skill Categories

  • Engineering: Solidity, Rust, TypeScript, React, Python, audits, DevOps.
  • Web3 Ops: Discord moderation, community management, growth, support.
  • Marketing: Twitter/X engagement, campaigns, KOL outreach, content.
  • Events: Event host, AMA host, speaker coordination, onboarding.
  • Research: Tokenomics, governance, ecosystem mapping, competitor analysis.

Credibility Inputs

Applicants can add GitHub, Twitter / X, Discord, LinkedIn, portfolio, and proof-of-work references. These are used to compute a stricter credibility score before submission.
